# Astro Starter Kit: Basics

```sh
npm create astro@latest -- --template basics
```
## 🚀 Project Structure

Inside of your Astro project, you'll see the following folders and files:

```text
/
├── public/
│   └── favicon.svg
├── src/
│   ├── layouts/
│   │   └── Layout.astro
│   └── pages/
│       └── index.astro
└── package.json
```

To learn more about the folder structure of an Astro project, refer to [our guide on project structure](https://docs.astro.build/en/basics/project-structure/).

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |

## 👀 Want to learn more?

Feel free to check [our documentation](https://docs.astro.build) or jump into our [Discord server](https://astro.build/chat).

<h2>Overview</h2>
<p>Velo-landing-page is a modern, Astro-based starter template crafted to build visually engaging and responsive landing pages with seamless Tailwind CSS integration. It provides a solid foundation for showcasing creative projects, such as independent films and portfolios, with a focus on performance and maintainability. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🛠️ <strong>Astro + Tailwind CSS Integration:</strong> Simplifies styling setup with Vite plugins for a cohesive design system.</li>
<li class="my-0">🔧 <strong>Modular Components:</strong> Reusable header, hero, and layout components ensure consistency and easy customization.</li>
<li class="my-0">📜 <strong>TypeScript Configuration:</strong> Enforces strict type safety, reducing errors and improving developer experience.</li>
<li class="my-0">🚀 <strong>Streamlined Workflow:</strong> Built-in scripts for development, building, and previewing facilitate rapid iteration.</li>
<li class="my-0">🎨 <strong>Focused on Creative Platforms:</strong> Designed to highlight visual content and user engagement effectively.</li>
</ul>
